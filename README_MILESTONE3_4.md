# Milestone 3.4 — Competition Edition / Classroom Release Candidate

**AI-Powered Boardroom — PromptEd 2026 Professional Track**

## What's new
- Consistent navy/teal visual theme across the single-decision studio and the three-round CEO Decision Lab, with responsive hero header, polished KPI cards, decision forms, and sidebar.
- Python-verified pricing and operations history in CEO Mentor feedback; the LLM is not asked to calculate financial values.
- AI narrative is restricted to three educational sections. Python always supplies exactly two feasible actions and one CEO question.
- New automated release tests covering deterministic outputs, budget limits, reflection requirements, real Round 3 operations regression, feedback structure, Ollama error handling, exports, and sensitivity.
- TXT learning summary now includes pricing and operations decisions per round.

## Install on Windows (8 GB RAM; Ollama optional)
1. Extract the ZIP; open Command Prompt inside `AI_Boardroom_PromptEd`.
2. `py -3.11 -m venv venv`
3. `venv\Scripts\activate`
4. `python -m pip install -r requirements.txt`
5. `streamlit run app.py`
6. Use **Demo mode** without an LLM, or install Ollama, download `llama3.2:1b` with `ollama pull llama3.2:1b`, and choose **Ollama (local, free)** in the sidebar.
7. Open **CEO Decision Lab** from the Streamlit page navigation for the full classroom experience.

## Test suite
`python -m unittest discover -s tests -v`

## Instructor pilot instructions
- Explain the fictional case and the ₹50 lakh one-time recovery investment ceiling.
- Ask students to make three cumulative revisions to **one year-one forecast**, not to simulate three calendar years.
- Require a rationale and a 12-word minimum reflection each round.
- Ask students to consult at least two advisor roles, analyze downside sensitivity, and export CSV/JSON/TXT.
- Discuss the difference between modelled revenue growth and first-year profit after investment.
- Collect anonymized evidence of completion, rubric results, reflection quality, and student feedback only with appropriate consent.
- Do not present rubric scores as validated managerial ability or modelled financial outputs as actual forecasts.

## Limitations
This is a release candidate, not a tested public deployment. Automated tests do not replace manual Streamlit UI and real Ollama tests. The numeric filter removes digit/currency lines from AI prose, but cannot prove all remaining qualitative statements are factual. The verified financial facts and action prompts are generated by Python. Data lives in the active Streamlit session only; no class-wide persistent instructor dashboard is included.
